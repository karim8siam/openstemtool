Simpson Biodiversity Index – Free Online Scientific Calculator

Compute Simpson’s diversity index from species abundances.

Interactive and free: change the example inputs, calculate results in your browser, and export the numerical result or a graph when available. This application requires JavaScript.

What this tool calculates

Compute Simpson’s diversity index from species abundances.. The calculation is performed locally with the model documented below. Use it to explore relationships between scientific quantities and to check your own classroom calculations.

Calculation method and underlying formula

D=Σnᵢ(nᵢ−1)/[N(N−1)], diversity index =1−D.
