2D Function Grapher – Free Online Scientific Calculator

Plot a safe mathematical expression with x, a, b and c. Function names include sin, cos, sqrt, exp, ln and log.

Interactive and free: change the example inputs, calculate results in your browser, and export the numerical result or a graph when available. This application requires JavaScript.

What this tool calculates

Plot mathematical functions with adjustable parameters. The calculation is performed locally with the model documented below. Use it to explore relationships between scientific quantities and to check your own classroom calculations.

Calculation method and underlying formula

Evaluated expression: sin(a*x) + b*cos(x). Trigonometric functions use radians.
